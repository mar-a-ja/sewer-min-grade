# Icon Water sewer grade (ACT)

Calculator for the minimum and maximum grade of a gravity sewer designed to Icon Water STD-SPE-G-011 (supplement to WSA 02-2014-3.3).

## Published site

The repository root is the site. It is meant to be a git submodule of the landing-page repository, mounted at `IconWaterSewerPipeGrade`, so it serves at:

> **https://chice.pages.dev/IconWaterSewerPipeGrade/**

Cloudflare Pages builds the landing page and pulls this repository in. There is no separate address. The pages that are served are `index.html`, `css/`, `js/` and `og.png`. `sources/`, `RESEARCH_NOTES.md` and the local server files are blocked by rules in the landing-page `_redirects`.

Local run: double-click `Start Website.cmd`, or `python serve.py`, then open **http://127.0.0.1:8766/**. Do not open `index.html` as a file — the page loads `js/engine.js` as a module.

## Going live

The catalog card and the `_redirects` rules are already in the landing-page repository. They point at `/IconWaterSewerPipeGrade/`. The submodule itself is added when this repository has a GitHub remote, the same way Valley Gutter is mounted:

```
cd <landing-page>
git submodule add ../<this-repo>.git IconWaterSewerPipeGrade
git commit -am "Publish the Icon Water sewer grade calculator"
git push
```

Pushing the landing page is what Cloudflare Pages builds. Push this repository first so the submodule has a commit to pin.

The Excel workbook remains in this folder as the record of the original sheet and the explicit workbook. The website is the working tool.

`og.png` is generated by `python tools/make_og.py`.
